⚙️ Learning page controls

Switch pages ON or OFF for this device. Changes apply immediately. To make the same defaults appear for everyone on GitHub Pages, download the settings file and upload it to your repository.

📷 Picture Library — Grown-ups

Add a photo or illustration once, then tag it with the correct learning page and word. The image automatically appears on that card. For images shared on every device, add files to the GitHub images folder and update image-assets.js instead. For example, choose Food & Drinks → Milk for a milk picture.

Pictures are saved only in this browser on this device. They do not automatically sync to other devices or into a GitHub ZIP. Avoid clearing browser data if you want to keep them.
